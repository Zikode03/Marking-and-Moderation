# Educator overview

The overview is shared by teachers, lecturers and professors, with content based on the selected organisation and the academic allocations returned by the API.

- Teachers see Grade 8–12 subject allocations and Teacher review.
- Lecturers and professors see faculty/module allocations and Academic review.
- Four summaries open the existing review, marking, moderation and completed queues.
- Attention items reflect real script states and available staff permissions.
- Recent batches show script counts, failed processing and approved-result progress. Opening a queue uses the existing queue workflow.
- Model readiness remains explicit; uploaded work is not presented as AI-marked before a model is ready.

The desktop sidebar stays at the top of the viewport with independently scrollable navigation and visible account controls. On mobile, the workspace navigation stays at the top and scrolls horizontally. Overview pages remain vertically scrollable; the single-screen requirement continues to apply to the public landing page.

Browser verification uses synthetic demonstration data, not production learner records.
